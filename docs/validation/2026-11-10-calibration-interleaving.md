# 清故障交错与事件拥塞回归

2026-11-10。本轮只新增测试与文档，没有修改产品源码。

新增UART场景calibration-interleaving：控制周期已完成旧CLEAR_FAULT但主循环尚未取走应答时，注入新的真实任务记录失败，验证旧清除返回WRONG_STATE、新故障仍锁存、ENABLE被拒绝；新序号清除才成功且不自动使能。该注入直接使用内部任务记录入口，是定向交错模拟，不是通过串口绕过故障启动新任务，也不是任意中断调度证明。

填满四个非遥测TX槽后连续两次尝试发送终态事件，验证事件ID/序号仍保留；排空后再次发送，正确失败结果仅入队一次，之后不重复。这里验证的是队列拥塞恢复，不承诺DMA失败、串口链路上的恰好一次投递。

使用既有MinGW，按tests/README.md的UART组合新编译；新增与此前20个独立进程场景合计21个全部通过。本轮未重建ARM/Qt，未连接硬件、烧录或运动。产品源码仍为前轮7D5932DF候选（正常构建/静态992B结论仅引用此前记录，不称本轮新跑）。能力与线协议不变，13请求/0x1A0。
