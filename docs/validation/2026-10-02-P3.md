# P3：通讯核心与模拟界面验证

日期：2026-10-02。环境：Windows、Qt5.14.2、MinGW7.3.0 64位，未安装工具。固件未修改，未打开真实串口。

## 范围与实现

- ITransport、SerialTransport：异步收发115200/8N1，软件及Qt发送积压合计上限432B，接收上限4096B，部分写入由bytesWritten继续提交；同线程拥有串口。
- SessionController：HELLO→INFO→STATUS→READ_PARAMS→TELEMETRY_CONFIG（能力决定后两步）；HELLO确认即开始100ms心跳，500ms无确认关闭会话。普通事务200ms，只读最多重试一次同SEQ，运动不重发；队列16项。
- 本机请求ID为quint64，线上SEQ实际发送时分配。STOP/DISABLE立即发送，取消排队运动及旧普通应答关联；等待停止确认期间拒绝新运动。无法撤回操作系统已接收的字节。
- MockTransport：协议V1模拟器，带延迟、丢应答、逐字节拆包、重启注入；四项/2000ms去重缓存及序号水位；独立心跳看门狗。同token HELLO保留水位，新token只可在禁用状态接管。提供参数读写、速度模式协议应答，不模拟真实机械响应。
- DeviceService拥有通信worker；UI线程DeviceStateModel维护确认值，500ms无新样本标记陈旧，旧采样不覆盖新状态。
- 主窗口：默认模拟连接，设备信息、状态、采样时间/计数、停止确认、断开重连、200行诊断日志。真实串口入口需确认V1固件；原P9旧协议不能直接连接。

## 验证过程与失败记录

1. `build/p3-red.log`：先增加会话测试，P3接口尚不存在时构建失败。
2. `build/p3-core.log`：通讯核心实现后原11项会话行为通过。
3. `build/p3-ui-red.log`：新增界面整合测试，因缺少connectButton而失败，确认测试能发现未实现功能。
4. `build/p3-ui.log`：旧版StepperHost.exe仍在运行，链接报Permission denied；保留用户窗口，构建/启动脚本增加BuildName参数，改用独立host-p3目录。清除三处误导缩进编译警告。
5. `build/p3-ui-green.log`：界面连接、状态更新、STOP确认、重连及活跃worker销毁通过；保存并查看`build/p3-window.png`，文字/控件完整。
6. 独立只读评审发现DISABLE取消路径缺失、任务ID未关联、Mock HELLO错误重置水位；均已修复，增加回归。额外过滤旧/重复采样，取消停止前旧查询应答关联。
7. `build/p3-final.log`：新陈旧采样测试仍用旧样本恢复新鲜度，断言失败；修正测试为收到新sample_counter后恢复，保留拒绝旧样本检查。
8. 二次评审修正参数ID1/2/3的profile上限映射，并让GET_STATUS/STOP即时快照也推进采样计数；补充关闭遥测后状态变化及参数上限回归。
9. 最终命令如下，结果见`build/p3-reviewed.log`及`build/host-p3/tests.log`，stderr见`build/host-p3/tests.err`。

```powershell
.\scripts\build-host.ps1 -Test -BuildName host-p3
```
