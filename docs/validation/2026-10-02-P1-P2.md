# 2026-10-02：P1 与 P2 帧层验证

## 环境与范围

Windows；Qt 5.14.2；QtTest 5.14.2；MinGW-W64 GCC 7.3.0；x86_64。分支codex/qt-host。QtWidgets最小窗口和协议帧层，无串口打开、无固件修改、无电机运动。

## 运行命令

在项目根目录PowerShell执行：`& '.\scripts\build-host.ps1' -Test`。

脚本用已有qmake递归生成工程、mingw32-make -j4构建；临时subst到空闲ASCII盘符以适配旧工具链，finally移除映射并恢复PATH。测试以Windows原生平台执行，并显式等待进程结束、读取退出码。

应用：`build/host/app/debug/StepperHost.exe`。测试：`build/host/tests/debug/host_tests.exe`。当前运行需要Qt/MinGW DLL搜索路径，`scripts/run-host.ps1 -ShowWindow`可按用户显式请求打开窗口；尚未制作独立发布包。

## 结果

- 应用与测试编译、链接成功。
- EnvironmentTest：4 passed、0 failed（含init/cleanup）；两个行为测试分别验证串口模块可实例化且不打开端口、主窗口默认未连接及显示/关闭。
- ProtocolTest：13 passed、0 failed（含init/cleanup）；11个行为测试包括CRC标准向量、黄金帧编码、所有拆分点、粘包、负数与内嵌帧头、坏CRC恢复、超长LEN恢复、4096B噪声与128B最大Payload、100ms半帧超时、非法版本/类型、reset。
- 原生平台最终运行没有QWARN；最小窗口截图已查看，中文显示正常。截图仅为窗口验证，不代表界面设计完成。
- 独立应用隐藏启动后进程存在；因隐藏窗口没有MainWindowHandle，CloseMainWindow不能关闭。已结束本轮自行创建的辅助进程；应用正常窗口显示与close由QtTest直接验证。

## 失败尝试与修正

1. 测试先行构建缺少MainWindow头文件，符合尚未实现的预期失败。
2. 中文目录被qmake/moc写成问号，出现moc预定义文件解析警告；短路径仍含中文，采用临时ASCII盘符后消除。
3. 初始测试INCLUDEPATH相对路径不适用于shadow build，改为基于$$PWD的源目录。
4. offscreen平台未找到Qt fonts目录、产生字体警告；改用Windows原生平台，不下载字体或改变Qt安装。
5. 协议测试首次构建缺少源文件，符合预期；文件创建后陈旧Makefile仍引用未解析路径，构建脚本改为qmake -r递归重生成。
