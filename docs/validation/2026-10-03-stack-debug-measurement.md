# 栈高水位与ISR调试测量方案（未执行）

范围：使用现有调试器，不修改启动/HAL/IRQ/链接文件，不使能电机。烧录或连接硬件前需用户确认。保持电机功率输出物理隔离；调试暂停会改变心跳与中断调度，软件禁用不能代替物理隔离。

## 固件身份与栈

以本轮最终全量候选HEX/AXF为一组，SHA256见[构建记录](2026-10-03-full-build-stack.md)。不能用原目录的旧HEX配新AXF。当前map给出Stack_Mem=0x20001DC8、__initial_sp=0x200021C8，栈1024B；这两个地址仅适用于本候选，每次重构建重查map。

1. 授权烧录后，从复位启动、在主循环首次进入前暂停；读取MSP/PSP、CONTROL，确认实际用栈与map一致。先保存完整栈区域快照。
2. 只填充尚未使用的栈区：从Stack_Mem至当前有效SP以下的空闲区写0xA5；绝不改SP以上的活动栈内容，不填堆或整个SRAM。若无法确认当前SP、填充边界或启动路径，不执行写入。
3. 恢复运行，保持禁用。覆盖握手、信息/状态、20ms遥测、STOP、快速重连、畸形/突发帧和心跳失联；每场景注明时间、帧量及固件身份。
4. 停机读取完整栈区，自低地址向高地址扫描连续未改的0xA5区域；其大小为该方法观察到的剩余量。保存原始内存快照，不只记录一个数字。重新初始化后分别重复负载场景。

限制：哨兵填充不能证明所有分支跑过，也可能漏掉仅调整SP但未写入的深度；可能恰好写出相同字节。补充有效SP的最小值采样和调用链分析。一次测量未溢出不是安全验收；目前没有采用已批准的运行余量阈值，32B静态门槛仅是本轮改进回归指标。

## ISR耗时

优先使用调试器已有周期计数/跟踪能力。Keil的Cortex-M3 States来自DWT_CYCCNT；模拟器不计入真实存储器等待周期，不能替代板端结果。[Keil Registers Window](https://www.keil.com/support/man/docs/uv4/uv4_db_dbg_cpuregs.asp)

- 核对实际核心时钟；先验证计数器确实递增。记录TIM4入口/出口对应周期值，按无符号32位差值除以时钟频率换算时间。
- 用断点读取的结果只作定位样本：暂停/调试开销会干扰时序，不能称连续运行最坏值。分别测控制服务、编码器及主循环UART负载，不将某个子函数耗时当作完整ISR耗时。
- 若调试器具备指令追踪，可记录连续运行中完整ISR及嵌套情况。Keil Execution Profiler需要支持ETM的适配器；尚未确认现有烧录器具备该能力，不要求安装或购买。[Keil Execution Profiler](https://www.keil.com/support/man/docs/uv4/uv4_db_dbg_execprofiler.asp)
- 若现有调试器无法取得可信连续时序，标记“未验收”；另行设计并确认GPIO/DWT插桩范围，不在本轮偷偷修改IRQ。

记录最小/最大/样本数、丢样和测量方式。20kHz名义周期50μs；测得ISR接近/超过该周期、栈余量不足、异常复位或中断嵌套违背静态假设时，停止后续功能开放并记录失败。不发送ENABLE或运动目标。
