# 校准失败锁存、快照与取消竞争

日期2026-11-10。正常配置候选，未烧录/实机操作。

校准任务失败锁存bit5，存储错误额外bit3；普通取消不设置校准失败。锁存阻止再次START及底层ENABLE，STOP/新会话/传感器恢复不清除。CLEAR_FAULT必须经既有控制周期完成，任务/存储忙时拒绝，完成收尾时再核对传感器有效、驱动禁用及故障代次；旧清除应答不得清掉后发生的新失败。清除不自动使能。未新增0502故障事件，故障通过状态/遥测与任务结果读取。

快照合并校准故障并优先FAULT；活动校准显示CALIBRATING，采集输出阶段电流字段为配置校准指令电流，计算/停止阶段保留控制器停机零值。它不是实测线圈电流，也不是瞬时PWM测量。

本次新编译20UART场景通过，新增calibration-faults验证250mA指令反馈、存储失败bit3/5、故障阻止使能/新校准、显式清除与无自动使能、取消待完成阻止下一代启动。初次预期两个取消同时入队失败；核对既有STOP单邮箱后修正为第二个BUSY，并保留该失败说明，未修改邮箱策略。
