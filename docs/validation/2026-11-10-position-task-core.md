# 受限位置任务纯软件核心

2026-11-10。用户要求电压问题暂不处理，继续离线开发；不解释为允许再次实机输出。电压异常仍保留。

新增固件Motor/position_move.h和tests/position_move_test.cpp，尚未接入工程运行路径、UART、邮箱、控制器或轨迹规划器。该类只管理单个目标的接收条件、限幅与终态，没有IO、自动使能、动态分配、递归或硬件时序变化。

调用者必须提供MoveLimits（距离/速度/加速度、位置/速度容差、连续到位样本数、超时），位置/距离为细分步，速度细分步/s，加速度细分步/s²，时间ms。超时上限120000ms来自协议基线，其他数值没有作为实机默认写入。测试的1000步/500步每秒/1000步每秒平方/2步/3步每秒/3样本只是测试夹具；不是用户批准的物理限值。测试按1ms观测示例，实际调用周期尚待接入。

接受需已使能位置模式、有效采样、有效校准、无故障且无活动任务。位移差先转int64再比较，覆盖INT32两极；速度/加速度先检查非零、INT32_MAX和调用者上限。到目标附近不直接成功：必须调用者明确通知规划完成，且位置误差/速度连续合格；越界清连续计数。故障、禁用或超时失败，cancel终止活动任务，恢复传感器不自动恢复失败任务。

本轮使用现有MinGW新编译-Wall -Wextra -Werror，position_move_test退出0，覆盖规划/实际区分、连续到位中断、采样失效/校准/模式/使能/故障拒绝、目标和速度加速度边界、极值溢出、正常时钟回绕、120秒超时、取消和终态保持。命令见固件tests/README.md。

没有跑ARM/Qt/既有协议全套、没有连接串口、烧录或运动，也没有提交推送。未接生产路径，不改变已烧录7D5932DF、13请求/0x1A0。该任务核心不是完整MOVE_ABS后端；尚缺轨迹规划、控制周期目标执行、任务ID/会话历史、事件、目标反馈与STOP/失联接入。
