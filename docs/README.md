## 最近状态摘要

- 下位机可处理 9 个请求命令，另有 11 个已定义请求尚未接入；详情以协议手册为准。
- 最新Qt99 passed、0 failed、0 skipped，包含初始化/清理与正常固件真实串口用例。
- 正常候选静态估算992B/1024B，仅余32B；旧840B作废。全量构建及烧录校验通过，仍未完成安全验收，见[全量构建](validation/2026-10-03-full-build-stack.md)。
- [正常模式禁用实测](validation/2026-10-03-normal-hardware.md)：两轮各255快照/48心跳、STOP确认及600ms后重连，不包含运动/物理停机/栈高水位测量。

这里只保留导航及少量摘要；字段布局不复制到其他文档，避免多份协议互相矛盾。状态变化时首先更新进度台账，再同步受影响文档；具体测试、提交及硬件边界以日期化记录为准。
