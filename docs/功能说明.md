# 当前功能与使用说明

最后更新：2026-10-03。适用当前未发布工作区，不适用原 P9 旧串口固件。

## 1. 项目用途与当前范围

目标是单电机串口调试、状态观察、运动控制及参数整定。目前可交付的是通信验证工具和第一批协议/安全服务，不是完整电机调试产品。协议详情集中在 [使用手册](protocol/串口协议V1使用手册.md)，进度集中在 [台账](项目进度记录.md)。

## 2. 上位机现有界面

| 功能 | 当前行为 | 边界 |
| --- | --- | --- |
| 模拟/串口模式选择 | 默认模拟，可选择协议 V1 串口设备 | 模拟数据不代表硬件；不自动识别旧 P9 协议 |
| 串口枚举/刷新 | 显示本机可用端口 | 当前实测 COM8，不硬编码每台电脑端口 |
| 固件确认 | 串口连接前勾选已烧录 V1 固件 | 这是用户确认，不是自动验证固件版本 |
| 连接/断开 | 打开串口、握手、信息/状态查询、遥测配置 | 连接不会自动使能；断开本身不等于已确认物理停机 |
| 状态与设备信息 | 显示连接状态、UID、版本、单位/圈、能力位 | 当前固件版本号不能唯一定位构建 |
| 快照显示 | 位置、速度、指令电流、设备时间、计数、故障位与新鲜度 | 指令电流不是实测电流；诊断固件不提供真实轴运动测量 |
| 停止并禁用 | Ready 后允许发 STOP，显示应答或结果未知 | 软件应答不是硬件急停认证 |
| 通信日志 | 启动阶段原始 TX/RX、超时诊断，最多 200 行 | 不是连续遥测数据录制或 CSV 导出 |

目前没有运动操作页、参数整定页、曲线绘图、CSV 记录、配置导入导出或校准操作页。界面底部仍有早期“P3 通讯验证”提示文案；该文案落后于当前诊断联调进度，不能作为状态依据。本次仅整理文档，未修改界面代码。

最新源码修复跨 token 的 HELLO 序号缓存碰撞；HELLO 应答丢失时原帧有界重试一次；P9 能力位纠正为 0x180。这些有软件回归，不应倒推已烧录旧诊断固件也包含修复。

命令框架同步已软件完成：Qt、通用核心与P9共用20命令载荷规则；P9显式支持清单仍为9项。未实现请求合法时返回UNSUPPORTED，载荷错误先返回BAD_PAYLOAD/OUT_OF_RANGE；拒绝不会进入控制邮箱或续期心跳。该变化没有增加界面或运动功能，见[验证记录](validation/2026-10-03-command-contract.md)。

## 5. 软件构建与启动

在 PowerShell 中执行：

```powershell
Set-Location -LiteralPath 'C:\Users\Cainiao\Documents\ChatGPT\42步进电机'
& '.\scripts\build-host.ps1' -Test -BuildName host-p4
& '.\scripts\run-host.ps1' -ShowWindow -BuildName host-p4
```

构建脚本临时映射 ASCII 盘符解决 Qt 5 中文路径问题，退出后恢复。启动脚本临时补齐当前进程 PATH，不修改系统 PATH，也不自动连接串口。

脚本默认不打开硬件串口；若环境变量 `STEPPER_TEST_PORT` 已被手工设置，则测试中的真实串口用例会启用，运行前检查。安全的独立硬件测试入口见下一节。

命令行和双击 EXE 本质是同一程序，但查找 DLL 的环境可能不同。当前应用不是独立发布包；缺少 Qt5SerialPort.dll 等运行库时，应使用现有启动脚本或完成规范部署，不能仅复制一个 EXE。此前本地 EXE 旁已补过运行库，不代表任意新构建目录都能独立运行。

## 6. 串口联调

接线为 USART1 重映射：PB6 TX → 转换器 RX，PB7 RX ← 转换器 TX，共地，3.3V TTL，115200/8N1，无流控。禁止直接使用 RS-232 电平。详见协议手册。

1. 核对实际烧录的是 V1 协议固件，不是持续文本发送或原样回传测试固件。
2. 关闭其他串口程序，选择端口并勾选 V1 固件确认。
3. 点击连接，等待通信 Ready；确认快照和心跳持续更新。
4. 可使用 STOP 检查软件应答；本阶段不发送使能、运动或校准。

只测基本收发成功不能证明协议正常；能握手也不能证明编码器、控制周期、功率级及 Flash 已验收。

关闭 Qt 连接后，可以分别执行：

```powershell
& '.\scripts\probe-serial.ps1' -Port COM8
& '.\scripts\test-real-serial.ps1' -Port COM8
```

不要同时运行。后者显式启用 Qt 真实链路测试，覆盖 Ready、遥测、心跳、STOP、重连，不使能/运动/校准。最新固件的快速重连和正常模式仍须另行验收；不要把旧诊断结果套用到新候选。

最新软件测试日志位于 `build/host-p4/tests.log`，会被下次测试覆盖；结果摘要保留在日期化验证记录中。命令框架同步后重新构建并运行，最新98 passed、0 failed、1 skipped，包含初始化/清理；跳过真实串口用例。

出现无回复、CRC 无效、BAD_SESSION、SEQ_CONFLICT 或 UNSUPPORTED 时，按协议手册的故障定位表区分接线、固件模式、帧格式、会话与未实现接口；不要通过反复下发运动命令排查通信。
