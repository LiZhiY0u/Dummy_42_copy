# 原版整合固件 v1：硬件测试说明

这是原版固件的修改版，目标 STM32F103CBT6（128 KB Flash、20 KB RAM）、MT6816、TB67H450。保持原版引脚映射和控制参数，未更改 P9 目录。它已通过云端交叉编译及主机测试，尚未经过实机验证。

## 获取与构建

- 下载提供的 ZIP：含源码、测试、HEX/BIN/ELF、SHA256SUMS 和本说明。
- 本地构建：安装 ARM GNU GCC（验证版本 14.2.1）、newlib/C++ 库、CMake >=3.20、Make；在仓库根目录执行 `bash tools/build_firmware.sh`。
- 运行主机测试：安装 g++，执行 `bash tests/run_host_tests.sh`。测试包含真实编码器逻辑、电机故障锁定、通信参数、CRC、UART 组帧及接收/发送缓冲区逻辑；硬件边界使用替身。
- 默认产物在 `build/firmware-v1/`。不要把 P9 的 Keil 工程当成本次修改的构建入口。

## 烧录与数据兼容

优先用 STM32CubeProgrammer/ST-Link 烧录 HEX。BIN 起始地址为 **0x08000000**，无 Bootloader 偏移。确认芯片实际为 128 KB Flash 型号；64 KB 型号不适用。

**本版修改了配置/校准数据格式，旧配置恢复默认值，旧校准表不再直接接受，必须重新校准。** 请先记录需要保留的参数。发布包不含任何预置校准表；校准数据必须由实际电机和编码器生成。

Flash 分区：

| 地址范围 | 用途 |
|---|---|
| 0x08000000–0x080177FF | 程序（94 KB，链接器限制） |
| 0x08017800–0x08017BFF | 校准版本、长度、CRC、最后写入的提交标记 |
| 0x08017C00–0x0801FBFF | 校准映射表（32 KB） |
| 0x0801FC00–0x0801FFFF | 版本化配置及 CRC（1 KB） |

校准擦除旧提交标记后再写表，逐半字检查返回值和回读，最后提交 CRC。配置使用单页保存，断电可能丢失新旧配置；下次启动会校验并回退默认值，不提供双副本掉电保留。写 Flash 时驱动休眠，按键不能启机，通信可能丢帧，完成后重新发送命令。

## 默认值与故障行为

- 节点默认 ID 为 1；原版已知设备序列号仍映射到 1–6。0 只作广播，不作为可配置节点 ID。
- 默认上电不使能，默认电流限制 1 A、速度限制 30 转/秒、加速度 100 转/秒²、校准电流 2 A。
- 固件命令允许范围：限流 1–2000 mA、速度限制 1–1536000 细分/秒、加速度 1–5120000 细分/秒²，位置命令 ±1000 转，DCE 系数 0–1000。范围只是软件上限，不代表你的硬件允许运行到该值。
- SPI 轮询有界；传输超时立即判失败，校验/无磁最多重读三次。采样最终无效时立即休眠驱动，并锁定故障；恢复连接不会自动继续运动。修复后复位，再显式启机。
- 状态灯沿用原版：未校准闪 1 次，堵转闪 2 次，过载闪 3 次；新增编码器故障闪 4 次、存储故障闪 5 次。
- 校准或故障期间拒绝运动/配置命令；校准期间允许停止命令取消校准。存储/编码器故障须复位。配置修改只在停止状态接受，保存也只在停止状态执行。
- 本版保留原版的默认堵转保护开关（关闭）。未增加通信失联自动停机；停止发送命令不会自动停止正在运行的电机。

## 串口（115200，8N1）

保留文本命令，可用换行或串口空闲结束：

| 命令 | 含义 |
|---|---|
| `s` | 停止/取消校准 |
| `c 0.1` | 电流目标 0.1 A |
| `v 0.1` | 速度目标 0.1 转/秒 |
| `p 0.1` | 位置目标 0.1 转（相对配置的零点） |

新增 P9 二进制五字节帧（高字节在前）：

| 帧 | 含义 |
|---|---|
| `AA 55 00 00 00` | 停止/取消校准 |
| `AA 55 02 HH LL` | 速度为 `(uint16(HHLL)-3000)/100` 转/秒 |
| `AA 55 01 HH LL` | 位置为 `(uint16(HHLL)-5000)/100` 转 |
| `AA 55 22 01 00` | 开启 100 Hz 速度回传 |
| `AA 55 22 00 00` | 关闭速度回传 |

速度回传为 `AA 55 22 HH LL`，解码 `(uint16(HHLL)-30000)/1000` 转/秒，超范围饱和。支持二进制拆包/粘包、跨 128 字节 DMA 接收块，接收不会停止发送 DMA。RX 硬件错误/软件队列溢出时丢弃不完整流至空闲边界后重新同步。二进制协议沿用 P9，无 CRC；线路噪声下不提供完整性保证，后续可升级带长度/CRC 的协议。

## CAN

沿用原版标准 11 位 ID：`(节点ID << 7) | 命令`，节点 0 为广播。默认时钟下保持原版位时序（1 Mbit/s），多字节数据小端。

- `0x01`：4 字节 uint32，0 停止，1 进入速度模式。
- `0x02`：显式开始校准，无数据要求。
- `0x03/04/05`：4 字节 float，分别为 A、转/秒、转；位置命令可追加第 5 字节非零请求应答。
- `0x06`：位置 float + 时间 float，必须 8 字节；**没有 ACK 标志**。不可达时间沿用原版的普通限速运动回退；速度不会超过配置限制。无效/非正时间直接拒绝。
- `0x07`：位置 float + 正速度限制 float，8 字节，速度不超过已配置速度上限，回传位置/完成标志。
- `0x11–0x1B`：沿用原版配置命令；有保存标志的命令必须附第 5 字节非零才保存；节点范围 1–15。
- `0x21/22/23/24`：电流、速度、位置、零点查询。
- `0x7E`：请求恢复默认配置，停机后执行并复位。
- `0x7F`：关闭驱动后复位。

短帧、远程帧、扩展帧、NaN/Inf 和超范围输入不改变控制目标。CAN 回复在邮箱忙时丢弃，不阻塞电机控制，请上位机超时重试。

## 推荐实机验证顺序

1. 电机空载、机构脱开，准备可直接切断电机供电的手段。烧录后检查驱动不自动输出、节点和串口可访问。
2. 编码器接好，上电同时按住两个原版按键，或发送 CAN `0x02` 校准。校准会按 2 A 设置驱动并往返转动，先确认电机及驱动允许；校准成功会自动复位。
3. 先设置较低的电流限制并保存，再以 `v 0.1`/`v -0.1` 和小幅位置命令测试；每次确认 `s` 能停止。
4. 在低速空载时模拟编码器通信故障/无磁，确认驱动休眠、故障灯闪 4 次；恢复连接后不得自动续转，复位后才可重新下命令。
5. 同时收发串口：测试拆包、连续 26 个五字节帧（130 字节）、启停速度回传；确认无错拼位置命令或截断遥测。
6. 测试 CAN 短帧、NaN、超限值和邮箱拥塞；确认不改变目标、不死机。修改节点 ID 后核实新 ID 生效及掉电保存。
7. 停止状态保存配置并复位，确认参数保留；恢复默认后复位，确认默认值恢复。写入时按启机键，确认驱动保持关闭。
8. 测量控制中断正常/异常路径耗时与 50 μs 周期、PWM/电流波形、实际温升。断电中断校准后，确认下次启动拒绝不完整表并保持不输出。

软件测试不能证明电流标定、硬件接线、实时性和电机稳定性；请按以上项目逐项记录结果。
