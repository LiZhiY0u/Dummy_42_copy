# Dummy 42 步进电机闭环驱动固件

复刻 Dummy 42 的 STM32 步进电机闭环驱动项目，GPL-3.0 开源。

## 未发布开发进展（2026-11-10）

已补编码器异常测试、校准取消/电流保护、分步Flash存储及提交记录、失败锁存和指令电流反馈。正常配置校准启动/取消/查询与任务事件已接入（13请求/0x1A0），诊断不开放启动（11请求/0x180）。7D5932DF候选已实机烧录，接线修正后校准成功且复位保持通过；不等于断电或完整运动安全验收。

后续位置任务核心、控制器目标适配及短行程量化收敛修复已完成离线测试，最新正常ARM候选2F1BC9...未烧录。MOVE_ABS/任务邮箱尚未接入，不能直接按完整运动控制使用。探针曾报告异常目标电压，真实供电未核实，暂不继续实际运动。权威进度/实测证据在codex/qt-host分支docs中。

校准格式现要求CAL1/version/length/CRC/最终提交标记，**旧数值表不再直接接受，需后续受控重新校准**。程序区限制为94KB，元数据0x08017800、表0x08017C00、配置0x0801FC00；只支持实际容量128KB的目标，64KB拒绝。四种配置构建和离线故障注入通过，不等于硬件断电验收。该节是未发布代码状态，以下历史实测仍按其原日期理解。

## 当前开发入口

- `main`：下位机长期开发主线，以已对接 Qt 串口 V1 的固件 `e58a194` 为基础。
- `codex/qt-host`：Qt 上位机及权威协议设计、使用手册。
- 当前主工程：[demo/P9.cbt6_motor_qt](demo/P9.cbt6_motor_qt)。Keil 工程位于其 `MDK-ARM/cbt6_demo3.uvprojx`。
- `原版/` 和其他 demo 暂作历史参考，不是当前 Qt V1 固件的构建入口。

## 已实现功能

- UART/DMA 接收、主循环分帧、CRC、会话/序号、请求去重与有界重试。
- 握手、设备信息、状态、心跳、遥测配置和上报，以及基础使能/禁用、STOP、故障清除接口。
- 控制周期邮箱及执行确认、心跳安全 Gate、部分旧 CAN 运动入口隔离；连接不自动使能，不自动恢复运动。
- 共定义20个请求命令，当前正常P9支持13个，命令组能力位 `0x1A0`；运动目标和参数持久化未接，校准尚无实机验收。

串口：USART1 重映射 **PB6 TX / PB7 RX，115200、8N1、3.3V TTL、共地**。当前协议不是旧五字节串口协议，不应混用或自动探测。

## 验证与进度

当前处于通信及安全服务联调阶段，尚不是完成运动验收的发布版。

- 历史正常固件禁用通信实测（2026-10-06）：Qt完整测试99通过/0失败，两轮握手、遥测、心跳、STOP应答与重连通过；未执行运动。
- 正常候选静态栈估算992B/1024B；一次禁用负载至STOP入口的哨兵观察写入跨度656B、未改368B。两者不是同一指标，均不能单独证明最坏栈安全。
- 完整ISR最坏耗时、异常/长期压力、失联物理停机、实际运动及电流安全仍未验收。软件STOP应答不是硬件急停证明。
- 上述为既有证据，本次分支整理未重新烧录或进行硬件测试。
