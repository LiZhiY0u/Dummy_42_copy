在项目根目录PowerShell构建并测试：

```powershell
.\scripts\build-host.ps1 -Test -BuildName host-p4
```

打开当前通讯验证窗口（默认模拟模式，点击“连接”）：

```powershell
.\scripts\run-host.ps1 -ShowWindow -BuildName host-p4
```

构建脚本使用临时ASCII盘符规避Qt 5工具链中文路径问题，不移动文件、不更改全局PATH。build输出被Git忽略，应用尚未打包为可独立分发版本。

当前输出使用 `build/host-p4/`。串口模式需要明确确认已刷入 V1 固件；原 P9 旧协议和文本/回传测试固件不能直接连接。默认构建测试不打开串口，除非已经设置 `STEPPER_TEST_PORT`；实际硬件测试入口见功能说明。模拟数据不代表硬件测量。

最新Qt含正常固件真实串口99 passed、0 failed、0 skipped（含初始化/清理）；正常候选已授权烧录并验证禁用通信，静态估算992B/1024B，仍须高水位及ISR验证。见[正常实测](docs/validation/2026-10-03-normal-hardware.md)。三处命令校验统一，能力仍0x180；连接不自动使能，STOP应答不等于物理急停证明。依赖已安装Qt/MinGW/Keil，尚无独立发布包。
